# Своя игра · Конституция РК 2026

Интерактивная учебная «Своя игра» по плану-конспекту занятия «Конституционное право Республики Казахстан». В проекте 15 вопросов в пяти категориях и 6 визуальных раундов «Угадай по картинке».

## Локальный запуск

Проект не требует сборки или зависимостей. Откройте `index.html` в браузере или запустите любой статический сервер из папки проекта:

```bash
python3 -m http.server 4173
```

После этого откройте `http://localhost:4173`.

## Возможности

- игровая сетка 5×3 с ростом стоимости от 100 до 500 очков;
- вариативные партии: вопросы перемешиваются при каждом запуске;
- режим для 2–4 команд без ввода текста: текущий ход, автоматическая передача хода, отдельные очки и лидерборд;
- финальный пьедестал с очками, верными ответами и точностью каждой команды;
- история до 12 завершённых партий сохраняется в браузере и открывается через «Статистика партий»;
- группа выбирает один из четырёх вариантов ответа, а ведущий фиксирует результат одного вопроса за раз;
- дополнительный визуальный раунд: 6 изображений, строго связанных с Казахстаном, его государственными символами и правовыми институтами;
- источники изображений и лицензии указаны в `assets/visual/SOURCES.md`;
- светлая адаптивная тема с пятью визуально разделёнными категориями;
- таймер с отдельным лимитом для каждого уровня;
- подсказки с уменьшением стоимости вопроса на 20%;
- серии ответов, прогресс, точность и финальный профиль;
- звуки успеха, ошибки и клика через Web Audio API;
- адаптивная верстка и поддержка `prefers-reduced-motion`.

## Источник контента

Учебные формулировки основаны на переданном плане-конспекте занятия. Игра не заменяет работу с официальным текстом Конституции.
